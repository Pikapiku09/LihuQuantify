# 论文筛选打分卡 + 主题优先级清单

> 配套：论文引入方案_dsh-invest与LihuQuantify迭代路线.md（工作区 Dify_Agents）
> 用途：Phase 0 —— 论文入库前的筛选工具。目标：淘汰 70%，只留可移植、可复现、有增量的少数。

## 一、使用流程

1. 每读完一篇论文（摘要+核心表+方法节即可），填一次打分卡（10 分钟内完成）。
2. 总分 ≥ 7 进入候选池（走三级门禁）；4–6 分搁置观察；≤ 3 分直接淘汰。
3. 打分卡连同论文 PDF/链接存入 `docs/papers/` 目录，文件名：`年份_第一作者_主题.pdf`。

## 二、打分卡（每项 0–2 分，满分 14）

| # | 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|---|
| 1 | A股可移植性 | 美国结构套利（做市/期权/隔夜机制） | 新兴市场/中国样本占部分 | 中国 A 股样本为主 |
| 2 | 数据可得性 | 需 Level2/高频/另类数据（Tushare 拿不到） | 需部分手工补充 | 日线+基本面即可（Tushare 全覆盖） |
| 3 | 机制清晰度 | 纯数据挖掘无机制 | 机制模糊（统计现象） | 行为/微观结构机制明确（可迁移） |
| 4 | 与现有策略互补性 | 与 CherryClaw/DeepDiagnose 重复 | 部分重叠但角度不同 | 全新维度（风控/执行/新因子族） |
| 5 | 复现成本 | 需重建整套模型 | 中等（数十行代码） | 低（一个因子函数 + IC 检验） |
| 6 | 预期 edge | 论文自述 t < 2 或未报显著性 | 中等（t 2–3，样本外一般） | 强（多市场验证/样本外持续） |
| 7 | 制度约束兼容 | 忽视 T+1/涨跌停/成本 | 部分讨论 | 已针对 A 股制度调整 |

**一票否决**（无论总分）：样本期 < 3 年；只报收益不报风险；因子构造用未来数据（如同期财务）；卖空假设在 A 股不可行且多空收益主要来自空头端。

## 三、主题优先级清单（按研究项目组织，非按论文堆砌）

### P1：动量/反转/换手（研究项目 #1）
- A 股短期反转与中期动量的期限结构；换手率/流动性溢价；T+1 下的动量实现方式
- 关键词：momentum, reversal, turnover premium, Chinese A-share, T+1
- 落点：research/factor.py → indicators → strategy

### P2：事件驱动 / PEAD（研究项目 #2）
- 业绩预告/快报公告后漂移；涨跌停制度下的事件反应不足；分析师覆盖变化
- 关键词：PEAD, earnings surprise, announcement, price limit
- 数据：forecast / express / anns_d（已接）
- 落点：事件回测（research 模块扩展）→ deep_diagnose 催化剂评分

### P3：资金流因子（研究项目 #3）
- 主力净流入的预测力与衰减速度；聪明钱/羊群效应；大单异动
- 关键词：order imbalance, money flow, smart money, herding
- 数据：moneyflow_dc / moneyflow_hk（已接）
- 落点：indicators + 消息面交叉验证

### P4：波动率目标 / 回撤控制（研究项目 #4）
- 波动率目标仓位；尾部风险控制；回撤约束下的最优风险预算
- 关键词：volatility targeting, drawdown control, position sizing
- 落点：risk/position_limit + stop_loss

### P5：执行与冲击成本（研究项目 #5）
- A 股下单冲击成本估计；拆单策略；流动性风险
- 关键词：market impact, optimal execution, A-share microstructure
- 落点：execution/oms + xtquant

### P6（方法论，持续）
- Deflated Sharpe / 多重检验 / Purged CV / 回测过拟合概率
- 不单独回测，用于校准门禁 2/3 的阈值

## 四、候选池管理

- 候选池上限 20 篇/季，防止「收集即终点」。
- 每篇进入门禁前登记：`papers/登记表.md`（题录 + 打分 + 一句话结论 + 计划试验次数 n_trials）。
- **n_trials 累计登记**：每个研究项目的 n_trials 总数如实累计，供 DSR 校正——这是防自欺的关键纪律。

## 五、已知系统局限（复现时注意）

- broker 涨跌停建模为主板 ±10% 一字板，ST/创业板不细分 → 涉及 300/688 标的的论文复现结论要打折扣。
- 回测为日线级：日内/高频论文一律归入「数据不可得」0 分。
