# 第五轮修复清单：邮件重构后的问题（for Trae）

> 项目：LihuQuantify
> 背景：邮件通知系统已完成重构（每交易日一封 HTML 综合日报，五模块：账户总览/持仓/操作/盈亏/风险）。本轮为重构后的代码审阅结论。
> 硬约束：策略/风控逻辑冻结，三口径（回测/模拟盘/实盘）不变，不改铁律数值。所有改动只涉及邮件通知与巡检数据聚合层。

---

## 修复 1（中·真 bug）：Markdown 报告资产口径与邮件不一致

**现状**：`src/lihu_quantify/monitor/scheduler.py` `_scan_impl` 内——
- 第 436 行 `asset = self.broker.query_asset()` 在**买入/卖出循环之前**抓取；
- 第 510-514 行生成 `.md` 报告仍用这份旧 `asset`（总资产/现金是交易前的）；
- 而第 502 行持仓列表是交易后的 `query_positions()`。

结果：`.md` 报告内"总资产/现金"与"持仓列表"自相矛盾，且与邮件日报（`_build_daily_summary` 内重新 `query_asset`，交易后口径）不一致。

**改法**：在生成报告前（约第 501 行 `positions = ...` 附近）**重新取一次** `asset = self.broker.query_asset()`，报告用这份新值。

**验收**：发生买入/卖出的交易日，`.md` 报告满足 `总资产 = 现金 + 持仓市值`，且与邮件日报数字一致。

---

## 修复 2（中低·真 bug）：当日买入被盖"昨日"日期 → T+1 守卫失效

**现状**：`on_new_day(latest)` 在**买入循环之后**（第 496 行）才调用，而 `PaperBroker.buy()` 记录 `self.trade_day`（此刻仍是上一交易日）。导致 `_check_stops_with_alert` 内 `buys_today` 判定（按 `trade date == latest` 过滤）永远匹配不到当日买入 → "当日新买持仓不做当日止损判定"的守卫失效，当日买入可能被当日 MA10 破位检查立即登记止损（正是该守卫要防的 churn）。

**改法**：把 `if hasattr(self.broker, "on_new_day"): self.broker.on_new_day(latest)` 从第 496 行**移到 `_scan_impl` 开头**（买入循环之前）。语义上也更正确：先解冻 T+1，再做今日操作。

**验收**：当日买入的持仓，当日止损检查日志不出现该票的"止损登记/MA10破位登记"。

---

## 修复 3（低）：连亏停手降级 WARN（避免"每日一封"例外）

**现状**：`alerts.py` 的 `alert_halt`（连亏停手）是 `LEVEL_ERROR` → `Alerter.send` 对 ERROR 即时发邮件，与"每交易日仅一封日报"目标冲突。

**改法**：`alert_halt` 的 level 改为 `LEVEL_WARN`（归入日报的风险提示区）。

**验收**：触发连亏停手时不再即时发邮件，当日日报的"连亏停手"栏目呈现该信息。

---

## 修复 4（低）：stop_registry 持久化（日报止损线准确）

**现状**：OMS 每次 scan 重建，`rebuild_stops_from_positions` 默认用"成本 -8%"，非原始止损价（`min(成本×0.92, MA10)`），日报"止损线"列为近似值。

**改法**：OMS 将 `stop_registry`（含原始 `stop_price`、`reason`）持久化到 `data/stop_registry.json`，重建时优先从文件恢复（文件缺失才回退成本-8%）。

**验收**：日报持仓表"止损线" = 买入时登记的原始止损价。

---

## 修复 5（低·加固）：HTML 转义

**现状**：`daily_report.py` 把股票名、拒绝原因、告警详情、报告路径直接拼进 HTML。

**改法**：对这些外部/用户来源字符串加 `html.escape()` 处理。

**验收**：含 `<`、`>`、`&` 的字符串在邮件中正常显示、不破坏表格结构。

---

## 实施顺序建议

**1 → 2 → 3 → 4 → 5**（1、2 优先，影响日报数字与止损纪律）。

## 回归基线（不可破坏）

- 单封 HTML 日报机制本身（每日一封、五模块）保持；
- 策略/风控/三口径冻结；
- 幂等、心跳、日志、备份等第四轮成果不回归。
