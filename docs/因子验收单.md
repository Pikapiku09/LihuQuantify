# 因子验收单（门禁2 硬标准）

> 自动生成：`lihu_quantify.research.evaluate_factor()`，输出字段与本单一一对应。
> 手工填写场景：门禁1 复现结果、门禁3 稳健性结论。

## 一、自动验收字段（evaluate_factor().as_dict()）

| 字段 | 含义 | 硬标准（缺一 FAIL） |
|---|---|---|
| factor_name | 因子名（FACTOR_REGISTRY 注册名） | — |
| rank_ic_mean | 逐日 RankIC 均值 | abs ≥ 0.02 |
| rank_ic_ir | ICIR = mean/std | abs ≥ 0.30 |
| rank_ic_t | IC 的 t 统计量 | abs ≥ 2.0 |
| long_short_ann | 成本后多空年化（按因子方向修正） | > 0 |
| group_monotonic | 分组均收益对组序号的 Spearman | abs ≥ 0.70 |
| turnover_mean | 多头组日均换手率 | 仅记录（越高成本敏感） |
| dsr | Deflated Sharpe Ratio | ≥ 0.95 |
| regime_consistency | bull/bear/range 下 IC 符号一致比例（可选） | ≥ 2/3 |
| gates | 各项通过布尔字典 | — |
| pass_all | 最终结论 | 全部 gate 为 True |
| notes | 未通过项与备注 | — |

## 二、调用示例

```python
import pandas as pd
from lihu_quantify.data.data_manager import DataManager          # 现有取数层
from lihu_quantify.research import compute_factor, evaluate_factor
from lihu_quantify.research.regime import classify_regime

panel = DataManager().load_panel(start="20190101", end="20241231")  # 列见 research 模块头注释
factor = compute_factor(panel, "momentum_20")
regime = classify_regime(DataManager().load_index("000001.SH"))

result = evaluate_factor(
    panel, factor, name="momentum_20",
    horizon=5, cost_bps=15.0,
    n_trials=1,          # ← 必须如实累计：本轮研究已试过的因子/参数总数（DSR 校正）
    regime=regime,
)
print(result.as_dict())   # pass_all == True 才允许进入门禁3
```

## 三、三级门禁登记（手工部分）

### 门禁1 可复现性
- [ ] 论文核心表在 A 股 2019–2024 小样本复现，方向一致
- [ ] 复现差异原因记录（数据/制度/样本期）
- 结论：通过 / 淘汰（原因：____）

### 门禁2 单因子（自动）
- 验收单 JSON 粘贴处：____
- n_trials 登记：本因子是本轮第 ____ 次试验
- 结论：pass_all = True / False

### 门禁3 组合稳健性
- [ ] walkforward（≥4 折，purge=前瞻期，embargo=2）各折 IC 符号一致
- [ ] 参数敏感性：主参数 ±30% 内结论不变
- [ ] 子样本（前后半段 / 大小盘 / 高低波）方向不反转
- [ ] regime 分层结论记录（若仅在单一 regime 有效 → 降级为择时条件使用）
- 结论：通过 / 淘汰 / 降级使用

## 四、通过后的落地动作

1. 因子函数固化进 research/factor.py（带论文出处注释与验收数据）；
2. 若可交易：进 indicators/ + strategy/（走策略级回测，用 EventDrivenEngine 全约束）；
3. 若为风控/仓位类：进 risk/；
4. 登记 docs/papers/登记表.md 更新状态为「已固化 + 验收日期 + 关键指标」；
5. （可选，仅探索层）dsh-invest-run 引用「Lihu 已验证」结论时的标准格式：
   `[已验证] momentum_20：RankIC=0.03x，ICIR=0.4x，成本后多空年化 +x%（2019–2024，DSR>0.95）`

## 五、与 metrics.py 的关系

验收单字段命名与 backtest/metrics.py 同风格（蛇形、可直接 JSON 归档）。
因子级（截面 IC 口径）与策略级（资金曲线口径，metrics.py）是两层：
门禁2 用验收单，策略级回测仍用 metrics.py + 月度复盘模板。
