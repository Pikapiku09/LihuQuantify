> 日期：2026-09-26 | 两阶段：① 首次网格暴露反直觉 → ② 定位修复 broker 滑点方向 bug → ③ 重跑网格与结论复验

## 一、发现的 bug（本次最大产出）

`backtest/broker.py` 市价单成交价：
```python
# bug（原）：买入 = open - slip，卖出 = open + slip → 倒收滑点（每笔"赚"0.2%）
# 修复后：买入 = open + slip，卖出 = open - slip
```
**影响范围**：所有历史回测（P1 策略化、P4 A/B、组合验证）都建立在低估成本的引擎上。
首次网格四组全部"滑点越高收益越高"即为该 bug 的显影。
engine.py 的 T+1 现金估算同源代码一并修复；3 个固化错误方向的测试断言同步更新（278 测试通过）。

## 二、修复后滑点敏感性网格（全部单调下降 ✓）

**判读**：
- IR20 高换手（100+ 笔/年）→ 滑点弹性 ~6pct/0.05%，**对执行成本高度敏感**；0.20% 滑点下样本外仅剩 +1.1%
- CC 换手相近但本身负收益，滑点弹性较小（~3pct）
- 实盘启示：IR20 要正贡献必须把单边成本控制在 0.15% 以内（含佣金+滑点+冲击）
