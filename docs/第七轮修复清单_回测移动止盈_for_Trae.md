# 第七轮修复清单：回测移动止盈公式（for Trae）

> 项目：LihuQuantify
> 背景：第六轮实现纸面移动止盈时发现**回测公式 bug**：
> `risk/stop_loss.py:117` 为 `trail_price = high_water_mark * (1 + trailing_pullback)`（即 ×1.03），
> 与其注释及文档口径"高水位×0.97（回撤 3% 离场）"矛盾。
> 由于 `hwm ≥ close` 恒成立，一旦 `hwm > cost`（出现任何浮盈），`close <= hwm×1.03` 恒成立 →
> **回测实际语义 = "出现浮盈即次日离场"**，而非"回撤 3% 离场"。
> 第三轮以来的全部网格/holdout 数字均基于此错误口径；纸面（第六轮）已按 ×0.97 正确实现。
> 本轮为 bug 修复 + 诊断，**不改变纸面行为、不改变 live 参数**。

---

## 修复 1（必做）：修正回测移动止盈公式

**现状**：`src/lihu_quantify/risk/stop_loss.py` 第 117 行：

```python
trail_price = high_water_mark * (1 + self.trailing_pullback)  # 高水位×0.97（注释）→ 实际 ×1.03
```

**改法**：

```python
trail_price = high_water_mark * (1 - self.trailing_pullback)  # 高水位×0.97（回撤3%离场）
```

同步修正：
- 该文件 `__init__` 中 `trailing_pullback = 0.03` 的注释确认语义；
- 引擎 `backtest/engine.py` 传参无需改（`trailing_stop` 已在离场分支）；
- 跑全量 pytest（163+），重点确认 trailing 相关测试（`test_round4_ops.py` 等）通过。

**验收**：`trail_price = hwm×0.97`；单测全过；回测中"浮盈后回撤 3%"才触发离场（而非浮盈即走）。

## 修复 2（诊断性重跑，不选参）：修正口径下参数存活性检查

**目的**：确认当前 live 参数 (0.05, 3, 0.08) 在**修正后的真实退出语义**下是否仍然有效——若修正后为负，说明该参数是 bug 口径的产物，必须早发现，而非等 100 笔纸面后才发现。

**改法**（本地跑，不动 NAS）：
1. 修复 1 落地后，对**训练段**（2024-07~2025-12，strat200 池）重跑一遍原网格（ma5∈{0.03,0.05,0.08,0.10}×fresh∈{2,3,5}×chase∈{0.06,0.08,0.10}，含停手+板块口径）；
2. 输出**修正前 vs 修正后对比表**（重点行：原参数 (0.05,3,0.08) 的总收益、邻域范围、稳健点数）；
3. 报告中明确标注"**诊断不选参**：本次重跑仅判定参数存活性，不据此改 live 参数"。

**判定标准**：
- 修正后原参数仍正收益且邻域全正 → "参数存活，继续 live，100 笔评审时以修正后回测为参考"；
- 修正后原参数转负 → "参数为 bug 口径产物，100 笔评审时需重选（届时走完整决策流程）"，并据此决定 live 是否继续（100 笔窗口保留，但结论标注）。

**验收**：产出对比表 + 明确结论（存活/不存活）；live 参数零改动。
