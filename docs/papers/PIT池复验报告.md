# Point-in-Time 池复验报告 —— 原结论无幸存者偏差，反而偏保守

> 日期：2026-09-27 | PIT 池：390 只（200 幸存 + 190 真退市，主板、2019-2026 间退市、代码未复用）
> 退市股数据：193,984 行前复权日线 | 判定：IC 同向且幅度不降 → 稳健

## 二、三个结论

1. **原研究结论无幸存者偏差**——加入退市股后 IC/ICIR/多空全面增强（0.0725→0.0875，+21%）。
   主板池的退市率低（190/390≈一半是历史累积退市，但对 2019 起的截面影响有限），
   且反转因子在退市股上更强——**原池结论是保守估计**。
2. **退市股子样本 IC 最高（0.1032）**：退市前的暴跌股日内超卖更极端，反弹更强——
   与因子逻辑（超卖越深反弹越大）自洽。同时提示：该因子的利润有一部分来自
   高风险边际股票，实盘需注意退市/流动性风险的尾部（策略层已有 ST/低价过滤）。
3. **ir20 转正评审的最大方法学疑虑被排除**：主账本因子的样本外/全区间结论
   在无偏池上成立。
