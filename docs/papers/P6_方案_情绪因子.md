# P6 研究方案：情绪因子（2026-09-27 制定，待启动）

> 定位：最后一个规划内研究项目。基于 P2/P3 教训（公开信息快速定价），P6 设计为
> 「低成本可证伪优先」——先用已有权限数据验证市场级情绪择时，个股级因子殿后。

## 一、研究问题与假设

**核心问题**：A 股情绪维度（涨停结构/题材热度/龙虎榜席位）能否（a）增强 IR20 的择时，（b）提供独立个股 alpha？

**假设（按可信度排序）**：
- H1（高）：市场级情绪（涨停家数/连板高度/炸板率）能识别情绪冰点/高潮，增强 block 择时
  ——依据：情绪四阶段循环（知识库_08）+ 金丝雀指标逻辑（知识库_04）
- H2（中）：龙虎榜席位结构（机构 vs 游资）有短期反向信息——游资接力=散户接盘前兆
- H3（低）：股吧/新闻 NLP 情绪有增量——公开文本大概率已定价（P2 教训）

## 三、因子/信号构造式（第一批）

### S1 市场情绪温度计（择时器，H1）
-涨停家数（非一字）5日均值 / 全市场数
-连板高度 = 当日最高连板数；高度 ≥5 = 情绪高潮预警
-炸板率 = 曾涨停后打开数 / 涨停数；>30% = 退潮信号
-合成：三指标 z-score 等权 → sentiment_score ∈ 冰点/回暖/过热
**验证**：sentiment_score 对 IR20 的开仓窗口选择是否优于现有 20 日涨幅 block
**预期用法**：替换/增强 market_filter（当前 reduce/block 基于指数均线，情绪口径更前瞻）

### S2 龙虎榜席位因子（个股级，H2）
-席位净买 = 机构席位买入额 − 卖出额（top_inst）
-游资热度 = 龙虎榜上榜次数（30日）
**验证**：披露后 5/20 日 IC（注意 P2 教训：龙虎榜也是公开信息，大概率 price-in——
预期为反向/零，验证后大概率登记为警示维度）

### S3 题材拥挤度（组合级，H1 延伸）
-概念主力净流入集中度（moneyflow_ind_dc 前三概念占比）
-与国泰海通拥挤度四指标（知识库）对齐：估值价差/配对相关留待数据补齐

## 五、风险与依赖

1. 龙虎榜接口权限未验证——第一步实测，无权限则 S2 降级为远期
2. 情绪择时与现有 market_filter 的重叠——需正交性检验（相关性<0.5 才有增量）
3. 涨停家数等指标 2019-2026 全历史需逐日拉取（limit_list_d 按日）——约 1800 次调用，
   需一次性建库（类似资金流管线）
4. 样本外纪律：2025-2026.8 留作最终验证，S1 调参不触碰
