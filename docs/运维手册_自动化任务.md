# 运维手册：自动化任务（2026-09-26 建立）

## 1. 研究面板周更（已注册 Windows 计划任务）

- 任务名：`LihuQuantify_PanelWeekly`
- 频率：每周日 20:00
- 动作：增量重建 research_panel（脚本自带断点续跑与缓存，无新数据时几分钟完成）
- 手动触发：`schtasks /run /tn LihuQuantify_PanelWeekly`

## 2. 知识时效季度复查（已注册，每周一 09:00 顺带检查）

- 脚本：`scripts/check_knowledge_freshness.py`，数据源 `data/verified_rules.json`
- 新增已验证规则时**必须同步登记**该 json（id/验证日期/复查周期）
- 任务名：`LihuQuantify_KnowledgeCheck`

## 3. dsh-invest 建议追踪（手动，建议每周五收盘后）

```
python scripts/track_dsh_advice.py register   # 登记本周新报告建议
python scripts/track_dsh_advice.py review     # 对账满20交易日的建议
```

## 4. 慧博研报自动归档（需一次性设置）

1. 慧博客户端 → 设置 → 默认下载目录改为 `F:\hibor_down`（目录会自动创建）
2. 注册每 10 分钟扫描（可选，或每次下载后手动跑）：
   ```
   schtasks /create /tn LihuQuantify_HiborWatch /tr "pwsh -File E:\LihuQuantify\scripts\hibor_watch.ps1" /sc minute /mo 10 /f
   ```
3. 新 PDF 自动以 `日期_原文件名` 归档到 `E:\Dsh_WorkSapce\Dify_Agents\PaperA-Stock`

## 5. Server酱微信通知（待填 key）

系统已内置支持，只差配置：
1. 微信搜索「Server酱」小程序 → 获取 SendKey
2. 填入 `config/settings.yaml` → `alert.serverchan_key: "SCT..."`（或 .env: LIHU_ALERT__SERVERCHAN_KEY）
3. 生效范围：止损触发/连亏停手/API异常/每日日报摘要
