## 三、判定与解读

1. **门禁1 判定：预告幅度维度不通过**——预告增速高低对事件后收益无显著区分力。
2. **提前定价证据**：预增组事件前 60 日 -3.5%、扭亏组 -5.5%（坏消息前已跌），
   预减组前 60 日 +9.3%（好消息前已涨）——**A 股业绩预告存在明显提前反应/泄密定价**，
   与国内文献一致。公告日买入已无肉。
3. 「略增」类 ret20 +8.7% 是 7 类中最大——但属多重比较（7 选 1），Bonferroni 后不显著，
   不能直接立项。全体事件 ret20 +4.17% 为池 beta（含 2025-26 牛市段），非事件效应。
4. 与 P1 结论呼应：A 股公开事件信息的快速定价，恰是「内幕-公开」时滞极短的体现；
   这也解释了为何量价类因子（intraday_rev）比事件类更有效。
