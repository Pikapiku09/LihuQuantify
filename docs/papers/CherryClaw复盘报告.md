## 二、根因：策略方向与已证 alpha 相反

1. **入场逻辑**：金叉 + 量比>1 + 实体≥40% + 贴 MA5 = **追短期动量**。
2. **我们的研究已证**（P1 门禁2）：**A 股 20 日动量是显著反向指标**（RankIC=-0.0445, t=-10.4）；
   20 日反转因子 IC 为正且三级门禁通关。
3. **结论**：CherryClaw 在**逆着已证 alpha 方向交易**——这不是参数问题，是方向问题。
4. 佐证：平均持有 **6.9 天**（卖出原因 top 全是"跌破 10 日线"）——它本质是**短线动量策略**，
   而非趋势策略；短周期正是反转效应最强的区间。

## 四、为何不做参数网格重搜（决策说明）

原参数（freshness=3, close_to_ma5=0.05 等）是在**含滑点 bug 的引擎**上网格搜索出来的，
理论上应重搜。但：
- **方向性错误无法用调参修复**——入场逻辑（追动量）与已证 alpha（反转）相反，
  参数优化的上限是"少亏"，不可能转正；
- 重搜在 4.67 年样本上做多维网格 → **过拟合风险远大于收益**（此前决策日志已有"变体脆弱"教训）；
- 研究预算应投入**方向正确的新策略**（如把 P1 的反转因子并入选股逻辑），而非修补负期望策略。

## 五、处置建议（待决策）

**方案 A（推荐，立即执行）**：主账本**停止 CherryClaw 新开仓**，权重降至 0；
现有持仓按原止损规则自然退出。IR20 从影子转为主力候选（但其 100 笔评审纪律尚在计数中，
可先以 50% 权重过渡）。

**方案 B（稳健过渡）**：按 25/75 配置过渡（IR20 为主 + CC 保留少量），
观察 1-2 个月后决策是否清零 CC。

**方案 C（研究驱动，中期）**：开发 **CC-Reversal 替代策略**——把入场逻辑从"追金叉动量"
改为"超卖回调买入（intraday_rev_20 因子）+ 趋势过滤（MA20 上方）"，走完整三级门禁后再上线。
这是把 P1 研究成果转化为实盘的正确路径。
