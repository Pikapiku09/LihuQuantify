# P4 报告：个股级波动率目标仓位——对趋势策略有效，对反转策略有害

> ⚠️ **2026-09-26 修订**：滑点 bug 修复后绝对水平下移（2025-26 base -24.50% / vt -13.57%；2022-24 base -9.89% / vt -7.98%），**vol_target 相对改善方向不变**。详见 P5 报告。

> 日期：2026-09-26 | A/B 对比（同引擎/费率/闸门，仅仓位缩放差异）| 目标波动 35%/年，回看 20 日，缩放下限 0.3
> 通过标准：回撤下降 + 卡玛提升 + 夏普不降

## 一、CherryClaw（趋势，reduce）——✅ 通过

| 段 | 收益 base→vt | 回撤 base→vt | 卡玛 base→vt |
|---|---|---|---|
| 2022 | +5.5% → +4.1% | -6.0% → -5.6% | 0.96 → 0.76 |
| 2023 | -10.1% → **-9.0%** | -11.6% → **-10.5%** | -0.90 → -0.88 |
| 2024 | +17.4% → +13.0% | -8.5% → **-5.8%** | 2.14 → **2.35** |
| 2025-26 | -6.3% → **+3.0%** | -19.3% → **-14.9%** | -0.21 → **+0.13** |

4 段中 3 段全面改善，**2025-26 扭亏为盈**（-6.3%→+3.0%，回撤同时降 4.4pct）；
仅 2022 微降（-1.4pct 收益）。对趋势策略：**波动高=趋势末端风险，减仓正确**。

## 二、IntradayReversal（反转，block）——❌ 不适用

| 段 | 收益 base→vt | 回撤 base→vt |
|---|---|---|
| 2024 | +11.9% → **+1.9%** | -14.5% → -15.2% |
| 2025-26 | +14.5% → **+2.3%** | -14.7% → -10.9% |

收益大幅缩水（-10pct 级），回撤几乎不降。**语义冲突**：反转策略买在超卖高波动点，
高波动是信号的"特征"（反弹弹性来源）而非"风险"——vol_target 恰在反弹主升段砍仓。

## 三、元发现（比 A/B 结果更有价值）

**波动率目标的适用性是策略语义依赖的**：
- 趋势策略：波动=不确定性 → 有效
- 反转策略：波动=机会 → 有害
任何风控规则上线前必须按策略类型分别 A/B，不能全局套用。

## 四、落地决策

1. **主账本 CherryClaw 启用 vol_target**（target_vol=0.35, min_scale=0.3）
2. **ir20 账本不启用**（反转语义冲突）
3. 配置化：settings.yaml → risk.vol_target（enabled/target_vol），默认开（主账本）；
   影子账本策略为 intraday_reversal 时自动跳过
