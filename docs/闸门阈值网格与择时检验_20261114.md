## 0. 结论摘要（先行）

1. **先前的"闸门很强"结论是未来函数的产物**。`lag=0`（把当日收盘算出的状态用在当日收益上）能**逐位复现**历史数字 `+71.63% / +34.11%`；改用与生产引擎一致的 T+1 后是 `+9.38% / +7.24%`（BH `+12.30%`）。**同一个未来函数把 9.38% 吹成 61.87%（同一清洗口径），虚增 52.49pp**；历史那份 `+71.63%` 比 `+61.87%` 高出的 9.76pp 全部来自伪交易日。
2. **在诚实口径下，闸门不提高收益，但能压低风险——且只有"旧严格"语义做得到**（全段 5bp）：旧严格 `MDD −3.95% / 卡玛 0.75 / 夏普 0.46`，BH `−15.17% / 0.44 / 0.47`，新宽松 `−11.23% / 0.30 / 0.41`。收益：旧严格 +5.33% < BH +12.30%。
3. **当前生产配置（3%/20日/r5≥2%）在风险调整上双输 BH**：卡玛 0.30 vs 0.44、夏普 0.41 vs 0.47。**2026-11-06 那次"放宽闸门"在指数层面是负贡献**。
4. **样本外没有任何一组参数能"稳定"跑赢 BH**：71/100 格样本外超额为正，但中位仅 **+1.48pp**；单点最优 +12.42pp 落在网格边角（阈值 1%、窗口 10 日，均为搜索区间端点），NW-t 仅 1.42，且样本内排名 72/100。
5. **不建议继续调参**：样本内→样本外排名 Spearman ρ = **−0.765**（p<0.0001）；"距最优 5pp"的平坦区只剩 9 格、阈值跨度 1pp、窗口只有 10 日一个取值——是**尖峰**不是平台。

## 1. 口径纠错记录

### 1.1 发生了什么

前序工作给出的"指数级闸门回测全段：旧严格 +34.1% / 新宽松 +71.6% / 买入持有 +9.3%"，以及"粗网格 13 组超额都在 +51.2pp ~ +76.6pp、区间平坦"，全部建立在**同日对齐**之上。

脚本以两种对齐方式跑同一段数据（无成本，`0bp`）：

| 闸门 | lag=0（含未来函数） | lag=1（T+1，正确） | 虚增 |
|---|---:|---:|---:|
| 新宽松 3%/20日/r5≥2% | **+61.87%** | **+9.38%** | **+52.49pp** |
| 旧严格 3%/20日 | **+34.11%** | **+7.24%** | **+26.87pp** |
| 买入持有 BH | +12.30% | +12.30% | 0 |

`+61.87%` 与历史记录的 `+71.6%` 差 −9.76pp，**实测全部来自那条伪交易日**（lag=0 下：未清洗 71.63% → 清洗后 61.87%）。区间起点口径对闸门策略**没有影响**（2025-01-02 首日闸门为空仓），但对 BH 有影响——见 2.3 节。

### 1.2 错在哪（机制）

`classify_market_state` 的三个输入**全部含当日收盘价**：

- `ret_w = close.pct_change(window)`：分母是 `close[t-window]`、分子是 **`close[t]`**；
- `ret_5`、`MA5`、`MA_w` 同理。

`lag=0` 的写法是 `pos[t] = state[t]`，而当日收益 `r[t] = close[t]/close[t-1]-1`——**信号里已经包含了它要去预测的那个收益**。指数 20 日动量与当日收益的相关性很高（当日涨跌约占 20 日动量的 1/20，且 regime 自相关强），于是策略"恰好"总在上涨日持仓。这不是策略，是数据泄漏。

生产引擎 `EventDrivenEngine` 是 **T+1 撮合**（`engine.py`：T 日盘后出信号 → T+1 撮合，`broker.fill` 用 `next_bar.open`），因此正确口径必须是 `pos[t] = state[t-1]`。

### 1.3 为什么"平坦区间"看起来那么美

未来函数的贡献对几乎所有参数组都是同向且巨大的，它把 100 个参数格**同时抬到 +50~76pp 的高位**，于是"区间很平坦"——**平坦的是泄漏红利，不是策略边缘**。去掉泄漏后，同一批格子的**样本外**超额落回 −3.86 ~ +12.42pp、中位 +1.48pp，平坦性随之消失（见 5.5 节）。

### 1.4 已加的三道防线

1. `assert_semantics()`：参数化闸门在**默认参数 (3, 20, 5, 2)** 下与官方 `classify_market_state` **逐日断言相等**（前 5 年 1271 天 + 全历史 8760 天全等），不等则 `SystemExit`；
2. `backtest_gate(..., lag=1)` 为默认，`lag=0` 需显式传参，且输出里标注"错误口径"；
3. 报告与 CSV 均以 T+1 为准，lag=0 只出现在本节的对照表里。

## 2. 伪交易日事故：2026-09-12

### 2.1 证据（脚本自动校验并打印）


旁证三条：

- 全历史 **唯一**一条周末行（`dow=5`，周六），也是 `trade_cal` 覆盖区间内唯一 `is_open=0` 的行；
- 成交量 14,258,747，仅为相邻交易日（约 5.79 亿）的 **2.5%**；
- 后一交易日 2026-09-14 的 `pre_close` 仍是 3888.11（= 09-11 收盘），交易所自身不认这一天。

**另一条独立证据**：本地 Tushare 原始响应缓存 `data/cache/index_daily_000001_SH_20301231_na.json` 共 8760 行，**不含** 09-12；与 DB 的 8760 个共同交易日收盘价**最大差 0.000000**，仅 DB 多这 1 天（`--source cache` 运行时的交叉核对输出）。即脏数据是入库环节引入的，不是数据源的。

### 2.2 影响（超过 5pp 的敏感度阈值，必须显式记录）

剔除这一行会同时改变：它自身的 `+4.73% / −4.59%` 尖峰、其后约 20 个交易日的 `ret_20d`/`MA20`、以及 09-12 当天的 `ret_5d`/`MA5`。

| 口径 | 当前配置 3%/20日/r5≥2% 样本外超额 | 样本外最优格 1%/10日/r5≥0% |
|---|---:|---:|
| 剔除伪交易日（采用） | **+0.79pp** | **+12.42pp** |
| 未剔除 | −1.94pp | +4.99pp |
| Δ | +2.73pp | **+7.42pp** |

100 格样本外超额的 Δ：均值 **+3.65pp**、最大 **+7.42pp**、`|Δ|>5pp` 的格数 **18/100**。**单条脏数据可以把样本外结论改写 7.42pp**——这与"1 个百分点的分位差让结论翻符号"是同一类风险，已在脚本里做成强制校验（`--keep-raw` 才能跳过）。

### 2.3 一处归因纠正

Lead 复核时把 `BH +12.30% vs +9.31%` 的差归到伪交易日上。实测：**同一窗口约定下，伪交易日对 BH 全段累计的贡献是 0.00pp**（+12.30% → +12.30%，`+4.73%` 与 `−4.59%` 几乎抵消）。那 2.99pp 的差来自**区间起点口径**：

- 本文（与 Lead 一致）：区间首日 `2025-01-02` 收盘建仓，收益从次日起算 → 448 个 bar / 447 个收益；
- 我最初的版本：把 `2025-01-02` 当天的收益（相对 2024-12-31 收盘，**−2.67%**）也计入 → 449 个收益，BH +9.31%。

两者都对，但**不能混用**。现统一采用前者（与 Lead 一致、且 IS/OOS 收益不重叠）。

## 3. 口径与方法

| 项目 | 定义 |
|---|---|
| 信号→仓位 | `pos[t] = 1{state[t-1] == 上涨}`（T+1，无未来函数） |
| 区间收益 | 区间首日收盘建仓，`equity[0]=1.0`，收益从次日起；IS 与 OOS 不重叠 |
| 成本 | 仓位单边变动 5bp（默认；另给 0/10bp）；BH 作为指数基准不计费（偏保守） |
| 累计/年化 | `total = equity[-1]-1`；`annual = (1+total)^(252/n_bars)-1`（与 `backtest/metrics.py` 的 `trading_days=252` 一致） |
| 波动率 | `std(daily, ddof=0) × sqrt(252)` |
| 夏普 | `annual / vol`（rf=0，与 Faber 2007 的 MAR 口径可比）；另列 repo 式 `sqrt(252)×mean/std` |
| 卡玛 | `annual / |MDD|` |
| 滚动 6 月胜率 | 126 交易日滚动窗口内策略区间收益 > 0 的比例；另给"跑赢 BH"比例 |
| 交易次数 | 区间内仓位变动次数（含区间首日建仓） |
| 样本内 IS | 2025-01-01 ~ 2025-12-31（243 日） |
| 样本外 OOS | 2026-01-01 ~ 2026-11-10（205 日） |

**与 Lead 独立复核的对齐**：0bp 口径下 BH `+12.30%`、新宽松 `+9.38%`、旧严格 `+7.24%`、MDD `−15.17% / −10.02% / −3.71%`、卡玛 `0.44 / 0.52 / 1.08`、持仓 `100% / 48.4% / 29.2%` —— **全部逐位一致**。
唯一差异在 5bp：本文新宽松 +6.04%、旧严格 +5.33%（Lead：+6.23% / +5.39%，差 0.19pp / 0.06pp），原因是本文对"区间首日建仓"也计一次成本、且成本按变动当日的权益水平复利计提。差异方向对本文不利（更保守）。

### 4.1 主表

**读法（这是本任务最重要的结论）**：

- **收益维度**：两个闸门都跑输 BH（5bp：−6.25pp / −6.97pp）。
- **风险维度**：旧严格把波动从 14.26% 砍到 6.40%（−55%）、回撤从 −15.17% 压到 −3.95%（−74%），代价是年化从 6.74% 降到 2.96%。
- **风险调整**：旧严格卡玛 0.75 **优于** BH 0.44，夏普 0.46 与 BH 0.47 **打平**；新宽松卡玛 0.30、夏普 0.41 **双输**。
- **成本敏感性（Lead 要求项）**：0bp 时两个闸门的夏普都不低于 BH（0.63/0.63 vs 0.47），**5bp 时新宽松跌破 BH**，**10bp 时旧严格也守不住**（卡玛 0.43 ≈ BH 0.44、夏普 0.30 < 0.47）。→ **"闸门改善风险调整"这个结论在 10bp 成本下不成立**，只在 0~5bp 的乐观成本假设下成立。这是一条必须写进结论的边界条件。

### 4.2 与 Faber (2007) 的对照

| | 收益（BH → 择时） | 波动（BH → 择时） | MAR/卡玛（BH → 择时） |
|---|---|---|---|
| Faber S&P500，10 月均线 | 11.24% → 11.18%（−0.06pp） | 17.47% → 14.00%（−3.47pp） | 0.25 → **0.48** |
| 本系统 旧严格（5bp） | 6.74% → 2.96%（**−3.78pp**） | 14.26% → 6.40%（−7.86pp） | 0.44 → **0.75** |
| 本系统 新宽松（5bp） | 6.74% → 3.36%（−3.38pp） | 14.26% → 8.20%（−6.06pp） | 0.44 → **0.30** |

**模式一致，量级更极端**：收益不提高（甚至降）、波动与回撤显著下降、MAR 上升——旧严格与 Faber 的结论同向。差别在于 Faber 的收益几乎不掉（−0.06pp），本系统掉 3.8pp，因为本系统平均只有 **29%** 时间在场（10 月均线择时的在市时间显著高于此）；这也是"MAR 从 0.44 抬到 0.75、抬升幅度与 Faber 的 0.25→0.48 类似"的原因。

⚠️ 三条局限：① Faber (2007) 是 S&P500 的长期样本，本样本只有 448 天；② Faber 数字由 Lead 提供、禁网未独立复核；③ 我们的择时规则是在同一段 2024-2026 数据上"设计过"的，Faber 的 10 月均线是事前规则——**可比性只在"模式"层面，不在"绩效"层面**。

### 5.4 旧严格 vs 新宽松（这是本次被推翻的结论）

| 比较维度 | 结果 |

| **全段卡玛（20 对）** | **严格胜只有 5/20**；均值 严格 0.19 vs 宽松 **0.36** |
| 全段最优 | 严格最好 0.77（1%/30日）；宽松最好 **1.19**（1%/10日/r5≥0%） |

**所以"旧严格系统性优于新宽松"只在样本外（2026 下跌段）成立，在全段不成立。** 机制清楚：宽松语义平均持仓 38.7%，是严格（19.4%）的两倍，回撤也接近两倍（−10.95% vs −5.49%）；2025 上涨段奖励高暴露、2026 下跌段惩罚高暴露。**结论的正确表述是**：

> 放宽闸门把持仓从 29.2% 提到 48.4%：在 2026 的下跌段，样本外超额从 +8.43pp（严格）掉到 +1.94pp（宽松）@3%/20日，同时多承担约 6pp 的回撤；在 2025 的上涨段则反向受益。**它改变的是 beta 暴露，不是择时精度**——这一点在下面的 TM 检验里得到独立印证。

### 5.5 平坦区间（三种定义）

| 定义 | 格数 | 阈值跨度 | 窗口跨度 | r5 跨度 | 区间内超额 |
|---|---:|---:|---:|---:|---|
| A：距样本外最优 5pp 内 | **9** | **1pp**（1~2%） | 仅 10 日 | 5pp（0~5%） | +7.46 ~ +12.42pp（跨度 4.96pp） |
| B：样本外超额 > 0（跑赢 BH） | **71** | **4pp**（1~5%） | 20 日（10~30） | 5pp | +0.22 ~ +12.42pp（跨度 **12.20pp**） |
| C：全段卡玛 > BH 0.44 | **9** | 3pp（1~4%） | 10 日（10~20） | 5pp | 卡玛 0.48 ~ 1.19（跨度 0.71） |

**"平坦区间跨度是多少 pp"的回答要分两层**：

- 若问"能跑赢 BH 的区域有多宽"：**很宽**（71% 的格，阈值跨度 4pp、窗口跨度 20 日、r5 跨度 5pp），但**很浅**——中位只有 +1.48pp，最薄的格 +0.22pp，与噪声不可区分；
- 若问"最优点周围有多平坦"：**不平坦**——定义 A 的 9 格全挤在"阈值 1~2% × 窗口 10 日"这个网格**边角**，阈值跨度仅 1pp。**这是尖峰，不是平台；而且是贴边界的尖峰，属于典型的过拟合形状。**

另外：全网格样本内→样本外超额的 Spearman ρ = **−0.765**（p<0.0001）。注意它的成因不是纯噪声——样本内（2025 上涨）奖励"多开仓"、样本外（2026 下跌）奖励"少开仓"，排名整体反转。**但实践含义相同：用 2025 选出来的参数，到 2026 会得到接近反向的排名。**

## 6. Treynor-Mazuy 择时检验

回归 `r_p = α + β·r_m + γ·r_m²`（rf=0，样本外，T+1，5bp）：

| 配置 | 超额pp | α 年化 | β | γ | t(γ) | p(γ) | β_up | β_dn | R² |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1%/10日/0% | +12.42 | −5.55% | 0.39 | **6.11** | **2.90** | **0.004** | 0.44 | 0.23 | 0.390 |
| 1%/10日/1% | +11.51 | −6.43% | 0.34 | 5.76 | 2.83 | 0.005 | 0.38 | 0.18 | 0.337 |
| 1%/10日/5% | +11.46 | −6.31% | 0.33 | 5.61 | 2.79 | 0.006 | 0.37 | 0.18 | 0.324 |
| 1%/10日/2% | +11.37 | −6.46% | 0.33 | 5.63 | 2.80 | 0.006 | 0.37 | 0.18 | 0.324 |
| 1%/10日/3% | +11.34 | −6.51% | 0.33 | 5.64 | 2.81 | 0.005 | 0.37 | 0.18 | 0.324 |
| **3%/20日/2%（当前）** | **+0.79** | **−1.18%** | 0.29 | **−2.55** | **−1.23** | **0.220** | **0.18** | **0.34** | 0.306 |

**读法**：

1. **当前配置没有择时能力**：γ = −2.55（t=−1.23，p=0.22，不显著且为负），且 **β_up 0.18 < β_dn 0.34**——下跌日的市场敏感度反而是上涨日的近两倍，**暴露方向做反了**。α 年化 −1.18%。
2. 网格顶部那 5 组 γ 显著为正（t≈2.8~2.9）、β_up > β_dn，形态上是**教科书式的择时**；但 α 年化为 −5.5% ~ −6.5%，即**择时赚到的风险调整改善全部以放弃收益为代价**——这与第 4 节"闸门=风险控制工具"的判断自洽。
3. ⚠️ **选择偏差警告**：这 5 组是"按样本外超额挑出来的"，γ 的显著性因此被抬高，**不能作为"系统能择时"的独立证据**。反过来，当前配置是**事前指定**的（不是按样本外挑的），它的 γ=−2.55 才是无偏读数。

## 7. 三问三答

**Q1：在 T+1 诚实口径下，是否存在任何一组参数能稳定跑赢 BH？**
**不能。** 三条证据：① **样本内 0/100 格**跑赢 BH（最好的一组仍落后 1.66pp）；② 全段只有 **1/100 格**在收益上赢 BH（1%/10日/r5≥0%，+0.89pp）；③ 样本外有 71/100 格为正，但中位只有 **+1.48pp**，最高的 +12.42pp 出现在网格**边角**（阈值 1%、窗口 10 日均为搜索端点）、NW-t 仅 **1.42**、样本内排名 **72/100**。**没有任何一格能在两个子区间同时跑赢 BH（0/100）。** 结论：所谓"跑赢"只出现在 2026 单一下跌窗口、幅度与噪声同量级、且以放弃 2025 的收益为代价——这不是 alpha，是 beta 管理。

**Q2：若都跑输，按卡玛排序的最优区间在哪？当前配置处于什么位置？**
样本外卡玛最优与全段卡玛最优是同一组：**1%/10日/r5≥0%**（样本外卡玛 0.81、全段卡玛 1.19、样本外超额 +12.42pp）。但它同样贴在网格边界上，样本内排名 72/100，**不建议采信**。当前配置：样本外卡玛 −0.88（71/100）、全段卡玛 0.30（低于 BH 0.44），**不在最优附近，且整片邻域都是负卡玛**。

**Q3：旧严格语义是否在网格里系统性优于新宽松？**
**只在一个方向上成立**：样本外 20/20 对（固定 rev=2%）或 17/20 对（每对取最优 rev）严格卡玛更高；**全段只有 5/20**，且宽松的均值卡玛（0.36）高于严格（0.19）。所以不能写成"旧严格系统性更优"，只能写成"**在 2026 这段下跌样本里，低暴露的严格语义风险调整更好；把两段合起来看，两者各有胜负，且都赢不了 BH 的风险调整水平（除 strict 的个别点）**"。

**是否值得继续调参？——不值得。** 三条理由：① 最优点贴在参数边界，无平台支撑；② IS→OOS 排名 ρ=−0.765（样本内 0/100 跑赢 BH，样本外 71/100 跑赢，排名整体反转）；③ 参数维度的收益差（1.7~4.8pp）小于单条脏数据的污染量（7.42pp）。**如果要继续投入，方向不是"调阈值"，而是"换语义"（例如把闸门定位为降仓系数而非二值开关、或用波动率目标替代开关）——这需要另开任务验证。**

## 8. 过拟合与样本局限（显式记录）

1. **样本内选参的局限**：IS（2025）只有 243 日、OOS（2026）只有 205 日，合计 448 个交易日 ≈ 1.8 年，只覆盖"一轮上涨 + 一轮下跌"。任何"最优参数"在这个样本量下都**没有统计意义**：样本外超额最高的那一组，其日频超额的 NW-t 也只有 **1.42**（远低于 2），中位组更低。
2. **"平坦性"比"最优点"更可信吗？——在这里两者都不可信，但理由不同**：先前那份"平坦"是未来函数造成的假平坦（5 个参数同时被抬到 +50~76pp）；现在这份"平坦"是**浅水区**（全部落在 −3.86~+12.42pp）。真正可用的判据不是"参数变一点结果不变"，而是"**在样本外、扣完成本、还能稳定为正**"——本网格没有满足这一条的格。
3. **制度性风险**：闸门是二值开关，一次误判就错过整段行情；2025 上涨段"宽松"赢、2026 下跌段"严格"赢，说明它更像 **beta 暴露调节器**，其最优取值取决于下一段市场的方向——**而那正是我们不知道的东西**。
4. **成本假设敏感**：0bp 时两个闸门夏普都 ≥ BH；5bp 新宽松失守；10bp 旧严格也失守。**实盘成本若高于 10bp 单边（或换手集中在高波动日），"闸门改善风险调整"的结论会整体消失。**
5. **单窗口、单标的**：只用 000001.SH 一条序列；没有做多标的（沪深 300 / 中证 500）与滚动窗口（walk-forward）交叉验证。
