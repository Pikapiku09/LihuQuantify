## 二、核心发现：主力净流入是显著反向指标

1. **方向确定**：主力（及超大单）净流入越多，未来 5-20 日越**跑输**——20 日口径 t=-6.5、icDSR=0.999，
   统计上铁证。与 A 股「主力流入=拉高出货/散户接盘」的实战认知一致（用户交易经验亦印证）。
2. **但吃不了成本**：IC 幅度小（-0.026），5 日持有期下 15bp 双边成本的年化拖累 ~150%，
   多空毛收益被吃光（20日口径成本后 -1.2%）。
3. **正确的使用定位：负向过滤/警示维度**，不是独立因子：
   - 20 日主力持续大幅净流入的票 → 未来一个月跑输概率高 → **排除条件**
   - 与 P1 因子组合：超卖反弹候选中，剔除主力仍在流入的（接盘未完成）→ 可能提升 intraday_rev 的 IC
4. 样本局限：仅 2024 起 2.7 年（未含完整熊市）——作为过滤维度可先用，独立因子需更长样本再验。
